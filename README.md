# E-Commerce App

A full stack e-commerce web application built with the MERN stack, featuring user authentication and product browsing functionality.

## Features

- **User Authentication** — Secure user signup and login system
- **Product Listing** — Browse and view product catalog with details
- **Responsive UI** — Built with React.js for a smooth, dynamic user experience
- **RESTful API** — Backend powered by Express.js with MongoDB for data persistence

## Tech Stack

**Frontend:** React.js, JavaScript, HTML5, CSS3

**Backend:** Node.js, Express.js

**Database:** MongoDB

## Getting Started

### Prerequisites
- Node.js installed
- MongoDB (local or Atlas connection)

### Installation

1. Clone the repository
```bash
git clone https://github.com/surekhagawade/ecommerce-app.git
cd ecommerce-app
```

2. Install backend dependencies
```bash
cd server
npm install
```

3. Install frontend dependencies
```bash
cd ../client
npm install
```

4. Set up environment variables (create a `.env` file in the server folder)
```
MONGO_URI=your_mongodb_connection_string
PORT=5000
```

5. Run the application
```bash
# In server folder
npm start

# In client folder (separate terminal)
npm start
```
